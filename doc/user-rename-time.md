# 用户名下次修改时间

登录及 `/api/user/get/login` 的已登录用户视图增加 `nextRenameTime`。普通用户本月改名限制存在时返回下月 1 日零点的 ISO 8601 时间，携带服务端时区偏移；没有限制、尚无用户名或既有角色豁免时返回 JSON null。沿用 `/api/user/update/my` 的自然月 Redis key，不使用用户资料更新时间推算，不改变原有改名权限、积分或限制写入。

前端按北京时间在用户名规则下显示，保存后复用原有资料回读。旧服务缺字段或返回无效时间时显示暂无法获取，不伪造可改状态。此字段仅为展示，实际保存继续由服务端校验。

验证：`UserRenameTimeTest` 覆盖自然月 key、下月零点、跨年、闰年及现有豁免；前端协议/格式/保存回读测试和全部注册主题、明暗模式、桌面/375px/390px 浏览器流程。
