鱼小圈积分打赏、管理页手动维护打赏榜、挑战失败、强化失败、写入失败、重复挖宝结算、重复支付回调均不触发。网站赞助原有聊天室感谢消息继续保留。

业务服务仅调用 `AchievementBroadcastService` 的对应入口，由它统一判断门槛、构造文案并注册事务提交后回调。回滚时不发送；推送或昵称查询失败只记录不含用户载荷的通用警告，不改变已提交的业务结果。管理员手动发布仍保留原有失败反馈。

播报只包含公开昵称、奖励、装备位置、层数或赞助金额，不带支付单号、凭证或留言。昵称清理控制字符、最多 40 个 Unicode 码点，缺失时使用“岛民”。既有用户及推送服务延迟注入，避免反向初始化业务依赖。

支付状态更新使用订单 ID 与 PENDING 条件，只有抢占成功的回调执行赞助结算与播报。此机制沿用数据库事务，不新增表、依赖或连接。播报为在线尽力投递，不保存历史、不补播，也不保证进程在提交后退出时仍能送达。
